# User Stories

## Auth

- As a visitor, I want to sign-up with an email and password or OAuth.
- As a visitor, I want to be able to log-in.
- As a user, I want to get a welcome email after succesful sign-up.
- As a user, I want to be able to reset my password.
- As a user, I want to log-out.

## Profile

- As a user, I want to set up a profile with a bio and profile image.
- As a user, I want to display my commission avaliability on my profile.
- As a user, I want to be able to edit my profile.
- As a user/visitor, I want to view any artist's profile page.
- As a user, I want extracted colors from my profile image to be used for faint background coloring on my profile page.

## Posts

- As a user, I want to make a post, edit and delete it.
- As a user, I want to be able to upload multuple images per post.
- As a user, I want to set a category for my post (oil, digital, etc).
- As a user, I want to be able to create tags (which when clicked should lead to the search page).
- As a user/visitor, I want view a post in full detail with its caption, tags and comments.

## Feed

- As a user, I want to see a feed of posts from artists I follow.
- As a user, I want my feed to be sorted chronologically, so that newest posts are first.
- As a user, I want to see random people's posts in my feed until I follow someone.
- As a user, I want the feed to load more posts as I scroll, but not infinitely (there should be a limit, after which user is reminded not to spend too much time on social media).

## Discovery & Search

- As a user/visitor, I want to browse an explore page.
- As a user/visitor, I want to search for artists by username.
- As a user/visitor, I want to search posts by category, popularity and date.

## Engagement

- As a user, I want to like/unlike a post.
- As a user, I want to bookmark a post to a private collection.
- As a user, I want to post/delete a comment on a post.
- As a user, I want to see all my bookmarks.

## Following

- As a user, I want to follow/unfollow an artist.
- As a user, I want to see a list of who I follow and who follows me.

## Notifications

- As a user, I want to be notified when someone follows me, likes and comments on my post.
- As a user, I want to se a badge with my unread notification count.
- As a user, I want to mark notifications as read.
